# Frontend patch: тарифные договоры

Этот пакет дополняет уже установленный backend-патч.

## Что меняется визуально

В карточке велосипеда старая форма создания аренды заменяется мастером:

1. выбор клиента;
2. выбор тарифа;
3. дополнительные батареи;
4. батарейные слоты:
   - существующая;
   - новая индексированная;
   - временная `TMP-BAT`;
5. число зарядок;
6. первоначальная оплата;
7. предпросмотр договора и графика;
8. создание договора одной кнопкой.

Для активного тарифного договора показываются:

- тариф;
- регулярная сумма;
- депозит;
- число батарей;
- выдача дополнительной батареи;
- закрытие договора.

## Правило оплаты

- Админский блок `PaymentRuleBlock` остаётся.
- Клиентский `ClientRuleRequestBlock` скрывается.
- Из клиентских общих запросов удаляется пункт `payment_rule_request`.

## Установка

Скопируй файлы в корень репозитория:

```text
components/rentals/RentalContractForm.tsx
app/api/admin/rental-contracts/options/route.ts
scripts/apply-rental-frontend-patch.mjs
```

Затем запусти:

```bash
node scripts/apply-rental-frontend-patch.mjs app/page.tsx
npm run build
```

После успешной сборки закоммить и задеплой.

## Зависимости

До этого должны быть установлены:

```text
lib/rentalContracts.ts
app/api/admin/rental-contracts/route.ts
app/api/admin/rental-contracts/add-battery/route.ts
SQL migration rental_plans
```

## Важно

Скрипт меняет только вызов старого `RentalActionsBlock`, а не удаляет его определение.
Это сделано специально, чтобы патч был устойчив к текущему большому монолитному
`app/page.tsx`. Неиспользуемая функция не мешает сборке при стандартной конфигурации
Next.js/TypeScript.
